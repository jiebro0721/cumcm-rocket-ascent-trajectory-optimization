### 2.2 修正问题二的终端约束实现

论文式 (24) 与式 (26) 使用 r=a、v_r=0、v_t=+sqrt(mu/a)，正号用于排除逆行圆轨道；但 src/common.py 的 orbit_residual 实际使用半径、速度大小和 r·v。该残差在数学上同时接受顺行与逆行圆轨道。问题三、四配点代码直接约束叉积为 +1，只有问题二仍保留分支歧义。当前根确实是顺行解，但模型、实现与论文的“严格排除逆行”并不一致。

```text
def orbit_residual_prograde(xf, rk):
    r = hypot(x, y)
    vr = (x*vx + y*vy) / r
    vt = (-y*vx + x*vy) / r
    return [(r-a)/a, vr/vc, (vt-vc)/vc]
```

## 三、P1：模型与数值证据的增强

### 3.1 不要只用两级网格证明“已收敛”

问题三的 10/20 与 20/40 网格目标差仅 0.012 kg，但独立传播的高度误差由 -0.668 m 变为约 -0.9 m，并未单调改善。这不表示解错误，只说明目标值稳定与轨迹离散误差收敛是两件事。代码中的 max_defect 字段实际读取 IPOPT 的 inf_pr，名称容易让人误以为已经计算了最大 Hermite-Simpson 缺陷。

25. 逐区间计算真实 HS 缺陷，并分别报告位置、速度、质量的最大无量纲缺陷。

26. 报告 NLP 的 primal infeasibility、dual infeasibility、complementarity 和 KKT 终止状态。

27. 把粗网格控制嵌入细网格后先独立传播，确认细网格求得的解没有因初始化或容差反而变差。

### 3.2 对问题四采用真正相关的路径约束

当前只允许二子级节流，二级点火高度约 117.7 km，且模型明确忽略一级分离后的气动阻力。因此“加入最大动压、热流后节流可能有收益”对当前二级节流模型并不直接成立：动压与热流主要发生在一级大气段，不能驱动已处于近真空的二级节流。对二级更相关的是轴向加速度、有效载荷过载、发动机节流速率和姿态角速度约束。

> **当前基准量级：**按统一传播器，一级最大动压约 27.9 kPa，一级末段推力/质量约 6.37 g。若引入 6 g 过载上限，连一级基准轨迹都会受影响，因此扩展模型必须说明约束适用于哪一级，并保持四问共同物理底座的一致性。

### 3.3 增加参数敏感性与鲁棒性分析

论文目前验证了积分容差和配点网格，却没有量化模型参数误差。数学建模评审通常更关心结论对简化假设是否稳定。建议至少考察大气密度倍率、阻力系数、推力、比冲、初始质量和一级分离时刻的扰动。特别是问题二至四采用开环控制，微小推力或比冲偏差会直接转化为终端轨道误差。

| 参数 | 建议扰动 | 观察量 | 解释目标 |
| --- | --- | --- | --- |
| 大气密度倍率 | 0.8 / 1.0 / 1.2 | 一级燃尽状态、最大动压 | 检验指数大气简化 |
| 阻力系数 CD | ±10% | 点火状态、终端误差 | 量化气动不确定性 |
| 二级推力 | ±1% | 高度、vr、vt、剩余燃料 | 检验开环控制鲁棒性 |
| 二级比冲 | ±1% | 燃烧时间与耗药 | 检验性能参数敏感性 |
| 初始/分离质量 | ±0.5% | 入轨误差与燃料裕量 | 检验质量估计误差 |

若篇幅允许，可在确定性最优解之后增加“校正燃料裕量”或场景鲁棒优化：在若干参数场景中共同满足终端容差，目标最小化最坏场景耗药。这样可以把当前 4553 kg 剩余推进剂解释为可用于闭环修正的裕量，而不只是一个结果数字。

### 3.4 增加轨道力学交叉诊断

问题一已经用近地点、远地点和偏心率说明并非圆轨道，这是很好的做法。建议对四问统一输出比机械能、比角动量、偏心率向量、近地点和远地点。终端圆轨道可同时用状态分量残差与轨道根数残差验证，能够发现坐标符号、速度方向和顺逆行分支错误。

### 4.2 工程扩展模型：让二级节流真正产生决策价值

在问题四后增加一个独立小节，不改变原题结论。把俯仰角作为状态而不是可瞬时跳变的控制量，并引入姿态角速度和节流比两个控制：

```text
扩展状态：x_e = [r_x, r_y, v_x, v_y, m, phi]
控制：u = [omega_phi, sigma]
dot(phi) = omega_phi
|omega_phi| <= omega_max
0.6 <= sigma <= 1
sigma*Fmax2/(m*g0) <= n_max
目标：min m(t2) - m(t3)，终端仍为顺行 400 km 圆轨道
```

建议把 n_max 取 3 g、4 g、5 g 做场景扫描，而不是无依据选定一个值。随着质量下降，加速度上限会迫使末段降推力，节流律有可能形成“满推力—受限节流”结构；姿态角速度上限会消除配点网格可能产生的瞬时转向。该扩展比在二级真空段加入最大动压或热流约束更有物理针对性。
